# Purity Product Update Carousel

## Purpose

Create a polished marketing carousel that introduces the latest Purity platform update in a way that is clear to both customers and managers.

The story should communicate one idea:

> Purity is now easier for customers to use and easier for managers to control.

Do not present the update as a technical release or mention source files, Supabase, APIs, TypeScript, or internal implementation details in the customer-facing artwork.

## Campaign direction

- Brand: **Purity Premium Technical Services**
- Market: Dubai, UAE
- Tone: premium, calm, trustworthy, practical
- Primary audience: homeowners and customers booking services
- Secondary audience: operations managers and business owners
- Language on artwork: English
- Supporting caption: English or Arabic according to the publishing channel
- Recommended format: 8-slide social carousel
- Recommended size: 1080 × 1350 px, 4:5 ratio
- Safe area: keep text inside 88% of the canvas
- Export: sRGB PNG or high-quality JPG, one file per slide

## Visual system

Use a consistent visual language across all slides:

- Warm off-white background: `#F8FAFC`
- Deep navy text: `#0F172A`
- Purity teal accent: `#0F766E`
- Emerald success accent: `#047857`
- Soft rose accent for saved items: `#E11D48`
- Subtle amber accent for offers: `#D97706`
- Rounded cards, light borders, soft shadows, generous whitespace
- Realistic Dubai home and service details, with diverse but natural customers
- UI mockups should look like a refined mobile product, not a generic dashboard template
- Use one strong focal point per slide and avoid overcrowding

Avoid:

- Fake statistics or unsupported promises
- Excessive discount language
- Generic stock-photo smiles without a service context
- Tiny UI text that cannot be read on mobile
- Too many icons, badges, gradients, or decorative elements
- Showing passwords, tokens, private customer data, or secret keys

## Design handoff checklist

- Use the same phone/dashboard frame style on every slide.
- Keep each slide to one headline and one supporting sentence.
- Set headline size between 64–88 px at 1080 × 1350 px.
- Set supporting copy between 28–36 px with comfortable line height.
- Use a maximum of two accent colors per slide.
- Add the Purity logo only after the generated background is approved.
- Add all final text in Figma or the design tool, not inside image generation.
- Check readability at 25% zoom before export.
- Export with consistent filenames: `purity-update-01.png` through `purity-update-08.png`.

## Feature coverage
